# ArcGIS Local Dictionary renderer for APP6-D

- app6d.stylx is from https://www.arcgis.com/home/item.html?id=ef2f9d1d572d405ab47675679b07ccd4
- dicitonaryInfo.json styles is from https://www.arcgis.com/sharing/rest/content/items/a63067c8791d4f88b308075af9587861/resources/styles/dictionary-info.json?f=json
- DictionaryRenderer local is an interceptor to resolve symbols locally instead of server side

## Run

```bash
bun dev:arcgis-dictionary-local
```
