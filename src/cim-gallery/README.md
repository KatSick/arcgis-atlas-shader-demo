# CIM dictionary rasterizer gallery

A no-map visual regression surface for the CIM pipeline: a spread of APP6-D
SIDCs (affiliations, planned status, echelons, mobility, HQ/TF/FD indicators,
operational condition, modifiers, direction of movement, text amplifiers)
rendered large, straight through `dictionary-script.ts` + `rasterizer.ts`.

Compare side-by-side with the official ArcGIS output in
`bun dev:arcgis-dictionary-local` to judge fidelity.

## Run

```bash
bun dev:cim-gallery
```
